AI 비서가
‘대신 해 주는’ 날.

최근 14호와 대조해 새로 수록한 소식은 36건입니다. 구글이 제미나이의 ‘작업(Tasks)’ 모드를 한국 등 6개국에 무료로 풀었고, OpenAI는 GPT-6.2 Astra·Sol을 내놓아 GitHub Copilot에도 같은 날 들어갔습니다. 국내에서도 버스표·식당 예약을 대신하는 AI 비서 ‘피클’, 대학생용 에이전트 ‘파이’ 등 ‘대신 처리’형 서비스가 이어졌습니다. 반면 구글은 기록을 꺼도 제미나이 대화를 2개월 보관하기로 해, 맡기는 만큼 개인정보 점검도 필요해졌습니다. 일부 사이트는 직접 열지 못했고, 본문을 읽지 못한 항목은 ‘제목 기준’으로 표시했습니다.

핵심 요약

  1. AI가 ‘답하는’ 단계에서 ‘대신 해 주는’ 단계로 넘어가고 있다. 구글은 예약·고지서·장보기를 처리하는 제미나이 ‘작업’ 모드를 한국 포함 6개국에 무료로 열었고, 국내에서는 피클(예매·예약 대행)과 튜링 ‘파이’(대학생 에이전트)가 나왔다.
  2. 모델 경쟁도 이어졌다. OpenAI가 GPT-6.2 Astra·Sol을, 마이크로소프트가 코딩 모델 MAI Code 2를 내놓았고 둘 다 GitHub Copilot에 바로 들어갔다. Copilot 코드 리뷰는 PR 난이도에 맞춰 검토 깊이를 자동으로 고른다.
  3. 맡기는 만큼 통제·검증 이슈도 커진다. 제미나이는 기록을 꺼도 대화를 2개월 보관하고, ‘게임’이라고 속이면 AI가 민간인을 표적으로 지목한다는 실험이 나왔다. 국내 글들(이오플래닛·요즘IT)은 에이전트의 ‘테스트 통과’ 보고를 사람이 다시 확인하는 법을 다뤘다.
